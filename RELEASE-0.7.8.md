# IONIQ Companion 0.7.8 — community preview

- Compact Find my car button below the vehicle image.
- On-demand Hyundai location retrieval, saved report timestamp and separate retrieval time.
- Phone-saved parking fallback captured when walk-away parking is marked, clearly distinguished from Hyundai's report.
