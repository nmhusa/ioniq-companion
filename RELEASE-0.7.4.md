# IONIQ Companion 0.7.4 — community preview

- Cleaner dashboard with expandable Settings & help.
- One refresh menu, compact report age and tap-to-view details.
- Vehicle-aware IONIQ 5/6 artwork and status overlay.
- Six colorful individual control widgets.
- Optional one-tap walk-away locking, with 20/30 m settings subject to GPS accuracy and network delay.
- Confirmations protect account changes and local-data erasure.

Android 8.0+. Hyundai US only; each user signs in with their own Bluelink account and remote-service PIN. Tested connectivity is limited to the owner's 2023 IONIQ 6. IONIQ 5 display support does not guarantee vehicle compatibility. Unofficial and unaffiliated with Hyundai/Kia.

Read INSTALL.md before installing. A switch from a debug-signed build to the release key requires uninstalling the old build and signing in again. Normal future release updates retain data when signed with the same key. Widgets send commands immediately, including Unlock. Walk-away locking is approximate; it does not automatically unlock on return.
