# IONIQ Companion 0.9.3 — car-battery icon

The 12V badge is now a scalable car-battery silhouette with two terminals, polarity marks, a subtle charge-level fill and the percentage inside. Existing amber/red/neutral colors, unknown handling and old-reading labels are preserved. Tap the battery for report details. No extra API calls or watch update.

Update and build in the existing project; install release-output/0.9.3/ioniq-companion-0.9.3.apk using the same signing key. The new view compiles locally against Android API classes; full Android build and device rendering remain pending.
