# IONIQ Companion 0.7.6 — community preview

- Saved front defrost, rear defrost and steering-wheel heating options applied with Climate on, including the home-screen widget.
- All three default off. Saving changes sends no command; in-app Climate on confirmation shows enabled options.
- Includes compact/resizable action widgets and the cleaner dashboard.

These request settings are not live heater status. Hyundai US encoding follows Bluelinky; actual behavior must be verified on the vehicle. No independent heated-seat controls are provided.

Read INSTALL.md before installing. API credential/artwork redistribution and signed-build device testing remain prerequisites to public release. The permanent release key is created locally; switching from a debug key requires uninstall/re-login. Future releases must retain the same key.
