# 0.9.6 — clearer lock failures

Unsuccessful or unconfirmed lock requests now show “Lock not confirmed” with a reminder to check the doors. Details suggest switching off the vehicle if it is on or in Utility Mode, without claiming this is the proven cause of every failure. Original redacted error details remain available. Applies to phone requests and requests through the command service, including Bluetooth auto-lock, widgets and watch feedback. No automatic retries or changes to reported vehicle lock state are introduced.

Build with the existing signing key. Output: release-output/0.9.6/ioniq-companion-0.9.6.apk. No watch update required.
