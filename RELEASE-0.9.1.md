# IONIQ Companion 0.9.1

The top-right control opposite the vehicle name is now a teal **Change vehicle ▾** button. It remains visible while connected, even with one cached car. Tap it to select a vehicle or refresh the enrolled vehicle list. The button allows two lines and grows vertically with text rather than clipping.

Includes the 0.9.0 paint picker and images. No watch update required. Use the latest update-existing-windows.ps1 and build-release-windows.ps1 in the existing project. Install release-output/0.9.1/ioniq-companion-0.9.1.apk over the existing app with the same signing key.

Android CI validation is pending; the local signed build script runs compilation and lint.
