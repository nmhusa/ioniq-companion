# IONIQ Companion 0.8.3 — Compact phone controls

- Shorter raised control buttons with visible labels and 42 dp icons; controls expand for larger text.
- Smaller car panel and title. Doors and climate appear first.
- Charging controls expand on demand. Climate options remain in presets; horn and lights remain in the Find my car options menu.
- Single-line command feedback opens full details when tapped. Vehicle report age remains visible separately.
- Compact automatic-lock status opens settings; no per-trip button is required. Paused monitoring is shown explicitly.

Bluetooth locking, command confirmation, unlock protection, widgets, and watch behavior are unchanged. No watch update is required.

Build with your existing signing key and install over the existing phone app. Never uninstall to update. Physical phone layout testing is still needed, especially with enlarged system text.
