# IONIQ Companion 0.8.8

Bluetooth auto-lock now offers 10, 15, 30, 60 and 120 second delays. New setups default to 15 seconds. Existing saved delays are preserved. To shorten an existing setup, open Auto-lock, select Lock delay, choose 15 (or 10) seconds, then Enable auto-lock again. This is a one-time setting change; there is no button press per trip.

The delay begins at the selected car Bluetooth disconnect, not door closure. Hyundai/network processing can add time before the car actually locks. Reconnection cancellation and single-attempt behavior are unchanged. No watch update is required.
