# IONIQ Companion 0.8.0 — Wear OS companion preview

Adds a separate Galaxy Watch/Wear OS app with vertical swipe pages for Doors, Climate, Charging, Find Car and cached Status. Essential controls are one tap; horn requires confirmation. Buttons show feedback while the phone processes a request.

The phone must be updated to 0.8.0, signed with the same existing key, and explicitly allow Watch controls under Settings & help. Existing phone unlock protection is enforced and is never bypassed by the watch. The watch has no Hyundai credentials. No real vehicle commands are sent during automated validation.

See WATCH.md for the two-APK build, wireless-debugging install and testing steps. Phone/watch background delivery and Samsung-specific gestures need paired hardware testing. This is a phone-dependent preview, not a standalone LTE app.
