Install the preview.

  1. Check GitHub Releases for a signed APK and read its release notes. If no APK is listed, a public binary has not been published yet.
  2. Download the APK to your Android phone, open it and allow installation from that source when Android asks.
  3. Sign in with your own Hyundai US account and remote-service PIN. Select your vehicle.
  4. Use “Add a home-screen widget” in the app, or your launcher's Widgets menu.

One tap means immediate action. The individual widgets do not ask for confirmation—including Unlock. Anyone using your unlocked home screen can tap them. Allow notifications to see command results.

Before you try it.

Which cars and phones?

Android 8.0 or newer. The underlying version 0.2 connection was tested by the owner with a US 2023 Hyundai IONIQ 6. Newer visual/widget builds need device testing. Other vehicles and regions are not verified. Active applicable Bluelink remote services are required.

Does “confirmed” mean live vehicle status?

It means Hyundai reported command completion. It is not an independent live sensor reading. Vehicle reports may be cached; inspect their timestamp. If completion is uncertain, check the official app before retrying.

Where do credentials go?

The app sends API requests directly to Hyundai over HTTPS. Credentials are encrypted locally using Android Keystore. The app has no analytics or developer-hosted backend. Read the privacy statement.

How do I report a problem?

Open a GitHub issue with the app version, Android version and error text. Never include your password, PIN, tokens or full VIN.
