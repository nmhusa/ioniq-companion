# IONIQ Companion 0.7.9 — community preview

Find my car now opens the map directly using saved Hyundai coordinates. If none are saved, it makes one on-demand request and opens the map after a valid response. The adjacent compact ⋯ control keeps timestamps, refresh, walking directions, clearing and the separately labeled phone parking fallback available without putting text on the main screen.

The map is opened in Google Maps or a browser, not embedded inside the app. Google displays the selected coordinates and any available address information. Cached coordinates may be old; check the timestamp and refresh in ⋯. Failed requests do not silently substitute a phone parking spot.

Install with the same permanent release signing key. Phone/car validation remains required. Public release authorization questions are unchanged.
