Privacy, plainly explained.

Applies to the source preview version 0.7.1.

The Android app

  • Uses your Hyundai account email, password and remote-service PIN to authenticate directly with Hyundai’s US API over HTTPS.
  • Stores credentials, session tokens and selected vehicle details encrypted in app-private storage with an Android Keystore key.
  • Stores vehicle status, last reported odometer with its vehicle association and update timestamp, command results and temperature preferences locally. Status and results can appear in widgets and notifications.
  • Contains no advertising, analytics SDK or developer-operated proxy/server. Hyundai processes the requests under its own terms and privacy practices.
  • Park & return optionally requests precise phone location and Nearby devices access. While a user-started monitoring session is active, it observes the chosen paired Bluetooth device and GPS movement. Parking coordinates are held in memory only and are not sent to the developer or Hyundai. The chosen device address, departure distance and monitoring status are saved locally. Location monitoring uses a visible foreground-service notification and stops when you stop the session. The app does not request contacts, microphone or camera. Internet, foreground-service and notification permissions support commands, monitoring and reminders.
  • Allows screenshots, screen recording and recent-app previews. Review captures before sharing them.

Removing data

“Disconnect and erase local data” removes saved credentials, vehicle status and command-result records. Parking settings are also removed. Temperature and other UI preferences may remain. Uninstalling removes app-private data. This does not delete your Hyundai account or Hyundai’s server records.

This website

This static page has no analytics, forms, login or third-party scripts. GitHub hosts the site and release downloads and may process connection metadata under GitHub’s privacy statement. Links to GitHub and Hyundai are governed by their respective policies.

Support

Use GitHub Issues for non-sensitive feedback. Issues are public. Never post credentials, PINs, authentication tokens or full VINs.
